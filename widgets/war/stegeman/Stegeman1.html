Type, or paste, premises into the lower panel. If there are several, separate them by commas, then, if there is a conclusion a 'therefore' symbol ∴ followed by that conclusion.e.g. copy all this

P, P ⊃ Q ∴ Q

and paste it in. Then Select whatever you wish in the lower panel and press 'Start from Selection'.
In the proof, the upper panel, select a single line by clicking on it, or multiple lines by cmd-clicking on several lines.
Choose a suitable rule off the Rules Menu to add a line.

To use the PME Rules, Select a line, Select 'Rewrite Rules' from the Rules Menu.
